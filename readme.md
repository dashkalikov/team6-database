# casi no

Учебное приложение с виртуальными монетами и одной слот-игрой для MVP. Денежные покупки, вывод и призы отсутствуют.

- [Архитектура БД — VC-65](docs/database/README.md)
- [Сервер и модель пользователя — VC-66](backend/README.md)
- [Игровой автомат и версии правил — VC-67](backend/games/README.md)
- [Атомарные игровые операции — VC-74](backend/finance/README.md)

Серверный компонент содержит пользователей, игры и версии правил, кошельки, раунды, финансовый журнал и базовые купоны. Синхронный спин рассчитывается на сервере и сохраняется одной транзакцией. HTTP API, сессии входа, административный аудит и пользовательский интерфейс реализуются отдельно.
